# Data Grid

**Status:** Hypothesis. Its acceptance criteria pass in automated tests. No user has tested it yet, so it has not moved to Draft (SPEC §11).

**Spec:** SPEC 7.1

## Purpose

One grid for every list of records: search, sort, filter, group, select and act, on a few rows or a quarter of a million. It is the surface most work happens on.

## When to use, and when not

**Use it** for any list a user scans, selects from or acts on. Use `kind: 'server'` for more than 10,000 rows or any unbounded list.

**Do not use it** for a short fixed list inside a panel (use a table), or for a batch on its way in (use the Batch Grid).

**With AG Grid Enterprise** (the default), the grid adds: server-side loading and grouping (with a drag-to-group panel), cell-range selection with decimal sums in the status bar, a column menu (sort, pin, autosize, group), a Columns tool panel, row numbers, Export to Excel at display precision, find-in-rows on client grids, and master/detail rows (`detail` prop). Enterprise features that would break a Ledgerline rule are not switched on: see `docs/AG-GRID-ENTERPRISE.md`.

## Foundations

Density tokens set row height (24, 32, 40). Financial columns right-align in tabular figures. Colour only ever backs up a word. The grid engine (AG Grid) is imported only inside `packages/ui/src/grid` and loads on demand.

## States

Loading, empty (no data), no matches (with the number of active filters), blocking error with retry, permission-limited, stale, processing (a bulk run in a job) and partial success (a results panel). Every active filter is a removable tag: there are no hidden filters.

## Data contract

`LLColumnDef<Row>[]` (financial, date, status, entity, text, boolean, delta), an `LLDataSource<Row>` (`client` rows or a `server` query returning `GridResponse<Row>`), `rowId`, and optionally `ActionDef<Row>[]`. Saved view state is `GridViewState`. The server query is the shared `GridQuery`.

## Permissions

`gridFeatures(segment)` switches capability by role: clients get no selection bar; new users see the preview before every confirm. Restricted columns cannot be copied or exported, and say why. `features.cellSelection` and `features.export` can be turned off per role; both are on by default. Actions come disabled with their reason, never hidden.

## Accessibility

Row and column counts are announced, including the server total. Every action reachable by mouse is reachable by keyboard (Shift+F10 opens the same menu). Focus, selection and scroll survive a refresh. Group rows name their group in words. A cell range is summarised in words in the status bar. Alt+Down and Alt+Up open and close a row's detail.
